## 実装面

- ほとんど初めてのホームページ制作で難しかった。JAVAとかよくわからなかったのでほとんどAIに頼ってしまった。
## デザイン面

-　自分の情報を整理して見せるために、四角いカードをたくさん並べるデザインにしました。
- カードごとに見出しを付け、何について書かれているのかがすぐ分かるようにしました。
- ゲーム、音楽、デバイス、ロードバイクなど、自分の好きなものが伝わるデザインを意識しました。
- 情報が多くなっても見づらくならないように、文章の長さやカード同士の余白を工夫しました。
- 色を多く使いすぎず、サイト全体に統一感が出るようにしました。
- 難しかったところは、ありのままの自分を表現しながら、暗い印象になりすぎないデザインにすることです。
